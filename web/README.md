# web

Finman's web app — React, governed by [`../starter/docs/architecture/02-FRONTEND.md`](../starter/docs/architecture/02-FRONTEND.md)
(framework-agnostic frontend contract) and [`../starter/docs/architecture/01-REACT.md`](../starter/docs/architecture/01-REACT.md)

conventions but no code, per `51-REACT-NATIVE.md` §1.

Not yet initialized — see [`../starter/docs/design/finman-design.md`](../starter/docs/design/finman-design.md) for
screens, navigation, and state classification, and the published roadmap for build order.
